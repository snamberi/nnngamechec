# Art provenance

Player master sheet generated and refined with the built-in ImageGen tool. The master uses a magenta chroma key; Godot removes that color and produces transparent frame sheets. There are no NBA, NBA 2K, or Hoop Land assets. Court, interface, indicators, and crowd are original code-native art.

## Initial generation prompt

Create a production 2D pixel art basketball player sprite animation sheet for a real game. Transparent background, no text, no labels, no grid lines, no shadows outside sprites, no watermark. EXACT regular grid 8 columns x 8 rows, square canvas 1024x1024, each cell exactly 128x128. Each cell contains ONE same athletic adult male basketball player, medium brown skin, short dark hair, cream white sleeveless jersey with navy side stripes and navy shorts, white socks, white/navy basketball sneakers. Sophisticated beautiful 32-bit-era sports pixel art, crisp deliberate pixel clusters, shaded musculature, polished proportions, substantial details; NOT stick figures, NOT neon, NOT glow. All frames same scale, whole body fits in each cell with 12px padding; feet baseline at y=112 within each cell when grounded. Player about 85 pixels high, 40 pixels wide at rest. Camera elevated 3/4 view appropriate for a top-down side court, facing screen right slightly toward viewer. 8 frames left to right in each row showing continuous well spaced animation phases. Row1 idle breathing and ready stance. Row2 running full stride cycle with alternating arms and legs. Row3 low dribbling running hand poses WITHOUT any basketball (ball drawn separately by engine). Row4 jump shot sequence crouch gather, hands raise above forehead, extension, follow-through, landing. Row5 one-handed layup sequence gather steps knee up arm extended finish then land, no basketball. Row6 two-handed dunk sequence crouch leap both arms reach overhead wrists snap then land, no basketball and no hoop. Row7 chest pass sequence gather at chest, extend arms forward right, follow through, recover, no basketball. Row8 defensive lateral shuffle sequence arms wide knees bent, then block jump raised arms, then land. All 64 distinct frames stay inside their own equal cells, same player and uniform consistent across sheet. Clean true transparent alpha around every sprite.

## Final refinement prompt

Convert this 8x8 basketball player sprite sheet to a classic game-engine chroma-key sprite sheet. ALL background, ALL red residue, ALL gray residue, ALL halos and smoke outside the players must be replaced by one perfectly uniform solid bright magenta color RGB(255,0,255). OPAQUE background no transparency at all. Keep all 64 basketball player figures, all their poses and exact regular grid arrangement, same scale. Carefully cut clean silhouettes around body and uniform and shoes, with hard pixel edges. No background remnants. No text. All pixels not part of player should be #FF00FF. Each of 64 cells contains only one basketball player against magenta. Preserve cream/navy uniforms and natural skin. Make a clean production game sprite texture atlas.

## Import and export

The generated master is `players.png`. Runtime cleanup removes the chroma key and edge residue, retains the connected player silhouette, fixes each frame to the same floor pivot, and creates six uniform/skin palettes. `tools/export_sheets.gd` writes the transparent `player_01.png` through `player_06.png` sheets and `animations.json`. Refer to `README.md` in this folder for frame layout and rebuild instructions.
